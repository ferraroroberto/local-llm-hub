# Project Instructions

Claude Code reads this file directly as project memory; other agents reach it via the `AGENTS.md` pointer.

## This repository
Local HTTP hub routing Anthropic- and OpenAI-shaped requests to multiple LLM/ASR backends, with a FastAPI + static-JS admin SPA at `/admin`. See `README.md` for setup, run and the doc index; [`docs/layout.md`](docs/layout.md) holds the file tree.

## Internal architecture

[`docs/architecture.mmd`](docs/architecture.mmd) is the repo's **only** component/runtime map (entry points, `src/server.py` routing to the Claude/Gemini/llama-server backends, process managers, `app_web/` admin sub-app, observability, config) — hand-authored, untested. Update it in the same PR as any material structural change (backend added/removed, router moved, process manager relocated). [`docs/project-structure.md`](docs/project-structure.md) points here and keeps only the per-backend request-lifecycle sequences plus the LLM key-facts briefing (#475). Model **placement** (which host owns which row) is [`config/models.yaml`](config/models.yaml)'s alone — never restate it in a doc.

**Safe restart (never blanket-kill python):** canonical restart is **`tray.bat --restart`** — kills the tray subtree, reclaims hub port **:8000** by PID scoped to this repo's `.venv`, then starts fresh. It deliberately does **not** touch `:8090` (whisper-server, mutex-shared with `voice-transcriber`) or the llama-server ports (8081/8082/8086/8087/8088). Fallback by hand only: find the owner with `Get-NetTCPConnection -LocalPort 8000`, stop that PID, relaunch via `tray.bat`. **Build confirmation:** `GET http://127.0.0.1:8000/health` returning 200 is *liveness* only — its payload (`{"status": "ok"}`) is identical across a restart. For build identity poll `GET http://127.0.0.1:8000/admin/api/version` and check `git_sha` changed — the auth-exempt endpoint `tray.bat`, `src/config_write.py` and `src/remote_stats.py`'s `peer_health()` already use.

## Verification gate

`scripts/verify-before-ship.ps1` runs CI's steps plus the ratchets: byte-compile, **static ratchet**, **docs ratchet**, comment ratchet, **structure ratchet**, **instruction ratchet**, **doc-refs ratchet**, **dead-code ratchet**, unit tests (`pytest -q --ignore=tests/e2e`), then e2e (`pytest tests/e2e -q --browser chromium`: Chromium only, one isolated hub per session), routed by the diff: `scripts/e2e_route.py` runs the vendored `scripts/classify_e2e.py` against `.fleet.toml [e2e]` and the gate runs nothing (docs/backend-only, with the router's reason printed), the static target, one surface's slice, or the full suite. Anything the router cannot read (non-zero exit, timeout, no or unknown `E2E_TIER`, a run tier with no target), an unclassified path or an empty diff runs the full suite and says why; it never runs less. The **static ratchet** (`scripts/static_ratchet.py`, vendored; `.fleet.toml [static_ratchet]`, baseline `.static-ratchet-baseline.json`) fails on a duplicate block (jscpd via `npx`, so Node is a prerequisite) or an unused import/variable (ruff `F401,F841`) that is not in the baseline; it reads the whole tree (`vendor/`, `data/`, `models/` and `_vendored/` excluded), so it is never path-routed, and the gate calls it only through `python -m scripts.static_ratchet_gate`, which fails exit 3 (a detector could not run) as NOT CONFIRMED, never a pass or a skip. Shrink the baseline in the PR that removes debt (`--update-baseline`); adding to it needs `--allow-additions` and shows in review. The **docs ratchet** (`scripts/docs_ratchet.py`, vendored; `.fleet.toml [docs_ratchet]`, baseline `.docs-ratchet-baseline.json`) fails when `README.md` passes 40 KiB or its baselined size, or when `README.md` or a `docs/**/*.md` file gains an issue reference, a dated heading or a changelog heading beyond its baseline (generated `docs/frontier/runs/` reports excluded); docs state the present-tense why, history lives in git, PRs and issues. It reads the whole tree, so it is never path-routed, and the gate calls it only through `python -m scripts.docs_ratchet_gate`, which fails exit 3 (a doc could not be read) as NOT CONFIRMED. A marker you must keep is baselined with `--update-baseline --allow-additions`, visible in review. The **structure ratchet** (`scripts/structure_ratchet.py`, vendored; `.fleet.toml [structure_ratchet]`, baseline `.structure-ratchet-baseline.json`) fails when a new file passes 1,000 lines, a new function 100 lines or a directory 40 modules, when a baselined offender grows past its recorded size, or when the root folders fall outside `shape = "service"` plus `extra_roots` in `.fleet.toml`. The baselined giants (`src/server.py`, `src/chat_translation.py`, `tests/test_streaming.py`, `app_web/static/styles.css` and `index.html`, the long SPA and streaming functions, the flat `src/` and `tests/`) sit at their real size, never excluded (only the generated `docs/frontier/runs/` reports are): they cannot grow, so a new module goes in a subpackage, not the flat directory. A new root folder is declared in `extra_roots` and given a line in `docs/layout.md`, not allowed by default. Re-vendor with `/propagate-vendored structure_ratchet`, never edit. Burn the baseline down with `--update-baseline`; only `--allow-additions` adds. The gate calls the script directly: its exit 3 (could not measure) fails the step like any non-zero exit. The **instruction ratchet** (`scripts/instruction_ratchet.py`, vendored; `.fleet.toml [instruction_ratchet]`, baseline `.instruction-ratchet-baseline.json`) fails when `CLAUDE.md`, `AGENTS.md` or a skill gains a prompt-audit lint-rule hit or passes a size cap beyond the baseline; whole tree, never path-routed, and the gate calls the script directly (exit 3 fails the step). Burn the baseline down with `--update-baseline`; only `--allow-additions` adds. The **doc-refs ratchet** (`scripts/doc_refs_ratchet.py`, vendored; `.fleet.toml [doc_refs_ratchet]`, baseline `.doc-refs-ratchet-baseline.json`) fails when `README.md`, `CLAUDE.md` or a `docs/**/*.md` file names a repo path, `python -m` module, relative link or loopback port that does not exist; another service's port or another repo's path named on purpose goes in `allow_refs`, not the baseline. Whole tree, never path-routed, and the gate calls the script directly (exit 3 fails the step). The **dead-code ratchet** (`scripts/dead_code_ratchet.py`, vendored; `.fleet.toml [dead_code_ratchet]`, baseline `.dead-code-ratchet-baseline.json`) fails when a Python function, class or method appears that nothing in the repo refers to (route handlers, `__all__` exports, tests and decorated hooks are never reported); whole tree, never path-routed, and the gate calls the script directly (exit 3 fails the step). Delete or call a flagged definition; a real framework entry point goes in `allow` / `entry_decorators`. Burn the baseline down with `--update-baseline`; only `--allow-additions` adds. **Measured runtime** (Windows, quiet box, 2026-10-15): about 6 min 30 s (390 s) end to end: unit tests about 302 s, e2e about 79 s. Test counts are deliberately not recorded here (they go stale every PR): `pytest --collect-only -q --ignore=tests/e2e | tail -1` prints the unit count, `pytest tests/e2e --collect-only -q --browser chromium | tail -1` the e2e node count. Whenever the e2e step runs it writes `data/e2e-junit.xml` (git-ignored, `[e2e] junit_xml` in `.fleet.toml`), which `/e2e-audit` reads for per-test seconds; a skipped step leaves the previous file untouched. The e2e figure above is the full suite; re-measure and update these numbers when the suite changes.

**Design inventory.** Each e2e surface is tagged with the vendored `surface(page, "<tab>.<surface>")` hook (`tests/e2e/_surface.py`, inert unless `DESIGN_SURFACE_CAPTURE` is set) at the first test that opens it, after that test's assertions, directly in the test body (the hook deselects any test whose own source never calls it). A new surface takes one such call; `/design-review measure local-llm-hub --e2e` walks them on a disposable hub and reports any overlay still not walked.
